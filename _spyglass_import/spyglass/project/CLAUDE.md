# Spyglass — project notes

## Design preferences (standing)
- **Section headers: bigger and bold.** Use a Geist 800, ~22px, tight-tracking heading for section titles (e.g. "Why Dana fits this search", "Résumé", "References") instead of small uppercase mono eyebrows. Keep the deep-gold (`#876B1E`) color for these on light surfaces.

## Brand quick-reference
- Accent: metallic gold `--amber #C2A24C` (fills/icons/rules); gold text on light uses deep gold `#876B1E`.
- Structure/CTA: navy `#0A1F3D`. Premium/positive moments: forest `#2F4D3A`. Negative only: red `#DC2626`.
- Type: Geist (human) + Geist Mono (system labels). Mark = cufflink housing (navy + gold).
