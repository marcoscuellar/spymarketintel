[ ASSIGNMENT RULE ]

Neutrals dominate. White, paper, ink and line carry ~80% of any view. The amber set is reserved for Engine 02 (Buying Signals) and its multi-vertical UI — never used as a generic warning color. The navy set is reserved for Standalone engines (Signal Audit · Seasonal Timing) and their dark-themed modals — never used as a generic brand blue.

Green is system-only. Live indicator dot, "Output" capability label, and the rare positive confirmation. Never a fill color on a card or button.

Type. Geist does everything. Geist Mono labels the system.

13 · MOTION
Hero fade-up
fadeUp · 0.7s · stagger 80ms

Eyebrow → h1 → sub → CTAs land in sequence, each with a 20px upward translate. Used on first render only; never on route changes.

Card hover lift
translateY(-2px) · 0.25s · ease

Primary CTAs lift 2px and gain a soft shadow. The inner arrow translates +3px. Never scale on press.

Active-state amber pulse
amberPulse · 4s · infinite

Box-shadow alternates between 18px and 30px amber glow. Engine 02 only. Never fast — 4 seconds keeps it ambient.

Standalone navy pulse
navyPulse · 4s · infinite

Mirrors amberPulse with navy rgba. Reserved for Signal Audit + Seasonal Timing. Never combine pulses on the same surface.

Modal pop
scale(0.95) → 1 · 0.45s · pop

The only place a pop-curve (0.34, 1.56, 0.64, 1) is allowed. Modal box overshoots and settles.

Standard ease
cubic-bezier(0.16, 1, 0.3, 1)

Default for every other transition. 180–250ms for hovers, 600ms for the 3D carousel rotation. Backdrop blur fades over 300ms.

[ 01 ]

Name the pain in quotes.

Every engine blurb opens with the rep-felt pain in quotation marks — "the bounce," "the Pre-Call Panic," "the Clean Slate." Quotes signal it's the operator's word, not marketing's.

[ 02 ]

Specific over general.

"60% of their day," "22% increase," "15+ hours saved." Every claim lands with a number that makes it auditable. Generic verbs ("accelerate," "scale," "empower") are banned unless followed by a metric.

[ 03 ]

System speaks in mono.

Anything the system says — status, engine name, timestamp, label — is Geist Mono in brackets or uppercase. The serif/sans is for humans. The mono is for the machine. Don't blur the two.

Founder surface. Photo + name + reason. In that order.

15 · FOUNDER
[ FOUNDER · BUILT BY THE OPERATOR ]

Marcos Cuellar. The operator who got tired of guessing.

GLVE started in late 2022 as a personal experiment — what if AI could automate the manual sales drudgery I kept hitting? The first engines were prototypes for my own pipeline. They worked. They got sharper. Today they run as one workflow.

The system is here because the problem was real. The voice is operator-first because the operator built it. Anything else would be marketing.

Built · 2022 Operator · not VC-built DOS · sibling product Active · 2026

The founder block is the only place a portrait appears on a GLVE surface. Always 4:5 aspect, 20px radius, on Paper background. Headline uses the two-tone display pattern. Stamps replace any "as featured in" rail — never use logos to borrow credibility.
